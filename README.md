# 스퀼라와 카륍디스의 해협 — 26-2 청송하우스 닫는 모임 부스 6

오디세이 테마 한 팀용 선택 게임.

- `index.html` — 배포되는 페이지 (직접 고치지 말고 빌드로 생성)
- `src/template.html` — 화면·규칙·연출 코드
- `src/data.js` — 시련 20개(4세트×5), 선물/저주 카드, 퀴즈, 미션
- `img/` 시련별 명화(퍼블릭 도메인), `art/` 스토리 그림, `icons/` 흑색상 도기 아이콘, `bgm.mp3` 자체 제작 배경음악

수정 후: `python3 build.py` → 커밋 → GitHub Pages가 1분 안에 다시 배포.
